# Vantara Workforce Solutions

> **B2B International Hospitality Workforce Platform**  
> *Connecting luxury resorts, island destinations, and hotel enterprises with verified, trained hospitality personnel across global talent corridors.*

---

## 🌴 Overview

**Vantara Workforce Solutions** is an international hospitality workforce coordination platform operated as a venture of **Ascentra Global Ltd**.

The platform is designed to provide luxury hospitality operators in premier tourist destinations (including Seychelles, Maldives, Belize, and expanding hubs) with vetted, uniformed talent across:
- **Food & Beverage Service & Mixology**
- **Culinary Arts & Kitchen Operations**
- **Front Office & Guest Relations**
- **Housekeeping & Villa Attendance**

---

## 🛠 Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Static Generation & Dynamic API Routes)
- **Language**: TypeScript
- **Styling**: Tailored Custom CSS Design System (Cormorant Garamond & Plus Jakarta Sans typography, dark forest luxury palette)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [Lenis Smooth Scroll](https://lenis.darkroom.engineering/)
- **Email & Delivery**: [Nodemailer](https://nodemailer.com/) with Google Workspace / Gmail SMTP integration

## 🚀 Getting Started

### 1. Clone the repository
\`\`\`bash
git clone https://github.com/zoaibahmed/vantara.git
cd vantara
\`\`\`

### 2. Install dependencies
\`\`\`bash
npm install
\`\`\`

### 3. Configure Environment Variables
Copy `.env.example` to `.env.local` and add your SMTP credentials:
\`\`\`bash
cp .env.example .env.local
\`\`\`

### 4. Run Development Server
\`\`\`bash
npm run dev
\`\`\`
Visit [http://localhost:3000](http://localhost:3000) to view the application.

### 5. Build for Production
\`\`\`bash
npm run build
npm run start
\`\`\`
